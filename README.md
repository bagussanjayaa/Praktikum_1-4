# Praktikum1-4

---

## Praktikum 1 - Pengenalan Framework CodeIgniter 4

Pada praktikum pertama dilakukan instalasi dan konfigurasi **CodeIgniter 4** secara manual. Langkah awal dimulai dengan mengaktifkan beberapa ekstensi PHP pada XAMPP seperti `php-json`, `php-mysqlnd`, `php-xml`, dan `php-intl`, kemudian menjalankan project menggunakan perintah `php spark`. Setelah itu mode debugging diaktifkan melalui file `.env` agar memudahkan proses pengembangan. Selanjutnya mempelajari struktur folder CodeIgniter, konsep **MVC (Model, View, Controller)**, membuat routing, controller, view, serta membuat layout sederhana menggunakan template header dan footer sehingga tampilan website menjadi lebih terstruktur. 

---

## Praktikum 2 - CRUD Data Artikel

Pada praktikum kedua dibuat aplikasi **CRUD (Create, Read, Update, Delete)** menggunakan CodeIgniter 4. Tahapan dimulai dengan membuat database dan tabel **artikel**, menghubungkan database melalui file `.env`, kemudian membuat **Model**, **Controller**, dan **View** untuk menampilkan data artikel. Setelah itu ditambahkan fitur detail artikel berdasarkan slug, halaman admin, serta fitur tambah, ubah, dan hapus data sehingga seluruh proses pengelolaan artikel dapat dilakukan melalui aplikasi web. 

---

## Praktikum 3 - View Layout dan View Cell

Praktikum ketiga membahas penggunaan **View Layout** dan **View Cell** agar tampilan website lebih modular. Dibuat layout utama (`main.php`) sebagai template yang digunakan oleh seluruh halaman. Selanjutnya dibuat **View Cell** untuk menampilkan widget **Artikel Terkini** pada sidebar. Dengan pendekatan ini, tampilan website menjadi lebih rapi, mudah dipelihara, dan komponen dapat digunakan kembali tanpa menuliskan kode yang sama berulang kali. 

---

## Praktikum 4 - Modul Login

Pada praktikum terakhir dibuat **Sistem Login** menggunakan CodeIgniter 4. Langkah yang dilakukan meliputi pembuatan tabel **user**, **UserModel**, **User Controller**, dan halaman login. Selanjutnya dibuat **Database Seeder** untuk menambahkan akun admin, kemudian diterapkan **Auth Filter** agar halaman admin hanya dapat diakses oleh pengguna yang telah login. Terakhir ditambahkan fitur **Logout** untuk menghapus session pengguna dan mengembalikan pengguna ke halaman login. 

---

# Kesimpulan

Melalui Praktikum 1–4, berhasil dipelajari dasar penggunaan **Framework CodeIgniter 4**, mulai dari proses instalasi, konfigurasi, penerapan konsep **MVC**, pembuatan **CRUD**, penggunaan **View Layout** dan **View Cell**, hingga implementasi **modul login** dengan **session** dan **Auth Filter**. Seluruh praktikum memberikan pemahaman mengenai cara membangun aplikasi web yang lebih terstruktur, modular, aman, dan mudah dikembangkan menggunakan framework CodeIgniter 4.
